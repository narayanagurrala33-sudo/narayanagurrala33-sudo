### 🛡️ JobShield 2.0 — Recruitment Safety Analysis Platform

A full-stack web application designed to help users identify potential warning signs in suspicious job advertisements and recruitment messages.

### ✨ Features

- 🔍 Recruitment risk analysis
- 📸 Screenshot OCR using Tesseract
- 🔐 Firebase user authentication
- 📊 Personal dashboard
- ☁️ Firestore report storage
- 📄 PDF and CSV report exports
- 🛡️ Protected backend APIs
- 🐳 Docker-based backend deployment
- 🌐 Public cloud hosting

### 🛠️ Technologies Used

React • TypeScript • Python • FastAPI • Firebase • Firestore • Docker • Tesseract OCR
